# antigravity-opencode-gemini

Плагин для **OpenCode V2**, который заменяет длинные встроенные системные инструкции краткими для моделей с ID `gemini-*`.

Создан как экспериментальный обход отказов Gemini через **CLIProxyAPI → Antigravity**. Не является официальным плагином Google, Antigravity или OpenCode.

## Когда стоит попробовать

- Короткий запрос через `curl` работает, включая SSE, `high`/`xhigh` и простой инструмент.
- Запросы OpenCode или его субагентов получают `429 RESOURCE_EXHAUSTED`, хотя модель отвечает на простые запросы.
- CLIProxyAPI после отказа сообщает `All credentials ... are cooling down` / `model_cooldown`, а OpenCode долго ожидает или повторяет запрос.
- Точное тело неудачного запроса воспроизводит отказ через `curl`, но удаление/упрощение системной инструкции помогает.

**Сам по себе HTTP 429 не является основанием устанавливать плагин.** Сначала проверьте реальные квоты, доступ аккаунта, частоту запросов и `Retry-After`. Плагин не увеличивает квоту, не снимает cooldown и не исправляет неправильный API-ключ или ненастроенный биллинг модели.

## Что показала диагностика

В исследованном случае с Gemini Hydrogen:

| Запрос | Результат |
| --- | --- |
| Короткий текст, streaming, варианты high/xhigh | 200 |
| Короткий текст с инструментом | 200 |
| Исходный запрос OpenCode с 12 инструментами и длинной системной инструкцией | 429 |
| То же тело без системной инструкции | 200 |
| Короткая нейтральная системная инструкция | 200 |
| Нейтральный текст той же длины в символах | 200 |
| Первая или вторая половина исходной инструкции в system | 429 |
| Исходный текст в user вместо system | 200 |

Равное число символов не означает равное число токенов. Эти результаты указывают на зависимость от содержимого/обработки системной инструкции, но **не доказывают фильтрацию, причину ошибки Google или универсальность обхода**. Временное состояние аккаунта также может влиять на результат. После упрощения инструкции тестовая генерация через сам OpenCode вернула успешный текстовый ответ; полноценный цикл вызова инструментов не проверен.

## Требования

- **OpenCode V2** с серверным API плагинов `setup(ctx)` и `ctx.session.hook` для `context`, `generate`, `compaction`, `title`.
- Проверено на **OpenCode 2.2.7**. Минимальная совместимая версия не установлена; V1 не поддерживается.
- Уже настроенный провайдер Gemini. Плагин не добавляет модели, авторизацию, CLIProxyAPI или аккаунты Antigravity.
- ID модели должен начинаться с `gemini-` (например, `gemini-4-hydrogen-xhigh`). Отображаемого названия недостаточно.
- Git для установки клонированием. Отдельная установка Node.js, Bun или npm-зависимостей для плагина не нужна: его загружает OpenCode.

В исходной диагностике использовался CLIProxyAPI 8.0.57; это не заявленная минимальная версия.

## Установка

### Вариант 1: один файл, глобально

```bash
mkdir -p ~/.config/opencode/plugins
curl --fail --location \
  https://raw.githubusercontent.com/d3TaL/antigravity-opencode-gemini/main/src/index.js \
  -o ~/.config/opencode/plugins/antigravity-opencode-gemini.js
```

Перед загрузкой убедитесь, что файл назначения не содержит ваших изменений. Если задан `$XDG_CONFIG_HOME`, используйте `$XDG_CONFIG_HOME/opencode/plugins` вместо `~/.config/opencode/plugins`.

### Вариант 2: клонирование и запись в конфигурации

```bash
git clone https://github.com/d3TaL/antigravity-opencode-gemini.git \
  ~/.config/opencode/antigravity-opencode-gemini
```

Добавьте абсолютный путь к клонированному каталогу в **существующий** массив `plugins` вашего `~/.config/opencode/opencode.jsonc`, сохранив остальные настройки:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "/absolute/path/to/antigravity-opencode-gemini"
  ]
}
```

Замените путь реальным. Не подключайте одновременно каталог и копию отдельного файла. npm-пакет не опубликован: установка по одному имени пакета не поддерживается.

Для проектной установки положите файл в `.opencode/plugins/antigravity-opencode-gemini.js` конкретного проекта.

OpenCode отслеживает изменения. Выполните `/reload`, чтобы принудительно перезагрузить плагины; перезапуск службы обычно не нужен.

**Если ранее установлен `gemini-concise-system.ts` из ручной настройки, отключите его перед подключением этого плагина:** оба реализуют один обход.

## Проверка

```bash
opencode --version
opencode api get /api/plugin
```

В списке должен быть `antigravity-opencode-gemini` со статусом `active`. Выберите Gemini и сначала отправьте короткий запрос. Затем отдельно проверьте рабочую задачу с инструментами. При 429 не запускайте непрерывные повторы: дождитесь `Retry-After` и проверьте upstream-логи. Перед публикацией логов удалите ключи, OAuth-токены, cookies и приватный контекст.

## Поведение и ограничения

- Применяется ко **всем провайдерам**, если ID модели начинается с `gemini-`; не только к CLIProxyAPI. Другие модели не изменяются.
- Сокращает системный текст для основного цикла, transient generation, compaction и заголовков.
- Краткая инструкция начинается с `You are a coding assistant running in Antigravity.` Это текст подсказки, **не смена реального клиента, upstream-маршрута или авторизации**.
- Не переносит системный текст в `user` и не меняет историю, инструменты, reasoning, модель, заголовки HTTP или разрешения OpenCode.
- Сохраняет уникальные инструкции из `metadata.experimental.instructions`, если их ключ **не** начинается с `core/`.
- **Весь остальной системный текст заменяется.** Если runtime или другой плагин не размечает проектные, агентские или пользовательские инструкции такими метаданными, они могут быть потеряны. Это не эквивалент исходному промпту и может изменить поведение специализированных агентов.
- Экспериментальные метаданные могут измениться между версиями OpenCode. Пользовательские инструкции, сохранённые через метаданные, также могут повторно вызвать исходный отказ.
- Краткий текст сохраняет общие правила защиты данных, разрешений, проверки результатов и запрета самовольных разрушительных действий. Это не замена серверной политике разрешений и не гарантия сохранения каждого исходного ограничения.

Проверьте важные проектные инструкции и правила агента после установки. Не используйте обход, если для вашей задачи критично точное сохранение всего системного промпта.

## Отключение

Удалите запись из `plugins` либо переместите установленный файл **за пределы** автоматически загружаемого каталога `plugins`. Выполните `/reload`. Исходные инструкции восстановятся для следующих запросов; история не менялась.

## Разработка

Основной файл: [`src/index.js`](src/index.js). Плагин не читает файлы, не обращается к сети самостоятельно и не хранит ключи или логи. Запросы к моделям выполняет OpenCode.

Документация API: [плагины](https://opencode.ai/docs/build/plugins), [серверные hooks](https://opencode.ai/docs/build/plugins/server).
